## `> pinned_projects`

### [R4BB1T_FHC](https://github.com/Mr4bb1t/R4bb1t_fhc) — `C++ · Arduino · ESP32 · CC1101 · NRF24L01`

ESP32-based cybersecurity hardware toolkit. Covers WiFi attacks (deauth, beacon spam, captive portal, MAC changer), Sub-GHz RF operations (replay attack, raw capture, RF analyzer) via CC1101, and 2.4GHz NRF24L01 scanning — all driven from a custom on-device menu interface.

`Embedded` `RF / Sub-GHz` `Cybersecurity` `Wi-Fi`

---

### [BlockerSpam](https://github.com/Mr4bb1t/BlockerSpam) — `Kotlin · Android SDK 34 · MVVM · Room DB`

Android app that silently intercepts and rejects calls from unknown/unsaved numbers using the `CallScreeningService` API. Logs blocked calls with timestamp, region and carrier. Full dark-mode UI, in-app auto-update via GitHub releases, 100% local — no cloud dependency.

`Android` `Mobile` `Security` `Privacy`

---

### [REMOTECODE](https://github.com/Mr4bb1t/RemoteCode) — `Python`

Remote code execution tool for running and managing scripts across machines over the network. Enables sending, executing and monitoring code on remote targets without physical access — useful for automation pipelines, embedded device management and lab control.

`Automation` `Networking` `Remote Exec`
